# Política de Privacidade

**Última atualização:** 27 de maio de 2026

## 2. Dados Pessoais Recolhidos

Recolhemos apenas os dados estritamente necessários ao funcionamento do Serviço:

### 2.1. Dados de Conta
- **E-mail** (obrigatório, para autenticação)
- **Palavra-passe** (armazenada em forma encriptada — nunca temos acesso ao texto original)
- **Data de criação da conta**

### 2.2. Dados de Utilização
- **Histórico de análises** efetuadas (produtos consultados, datas)
- **Configurações pessoais** (margem-alvo, região de mercado, preferências)
- **Logs técnicos** (data/hora de acesso, IP — retidos por 30 dias para segurança)

### 2.3. Dados de Integração (Opcional)
Caso decida integrar com o **Bling V3** ou outras plataformas:
- **Tokens OAuth** (encriptados, permitem que o Serviço consulte/atualize a sua loja)
- **Identificadores de produtos** (SKU, ID interno)
- **Preços de custo e venda** (necessários para os cálculos)

### 2.4. Dados que **NÃO** Recolhemos
- Nome completo (a menos que voluntariamente fornecido)
- Documentos de identificação
- Dados bancários ou de cartão de crédito (durante a fase Beta gratuita)
- Localização precisa
- Dados de navegação fora do Serviço

|------|---------------------|
| Conta ativa | Enquanto a conta existir |
| Histórico de análises | 12 meses após criação |

## 7. Direitos do Titular dos Dados

Como Utilizador, tem os seguintes direitos garantidos pela LGPD e GDPR:

| Direito | Descrição |
|---------|-----------|
| **Acesso** | Saber que dados temos sobre si |
| **Retificação** | Corrigir dados incorretos |
| **Eliminação** | Solicitar exclusão dos seus dados ("direito ao esquecimento") |
| **Portabilidade** | Receber os seus dados em formato estruturado (JSON/CSV) |
| **Oposição** | Opor-se ao tratamento baseado em legítimo interesse |
| **Revogação de consentimento** | Retirar o consentimento a qualquer momento |
| **Reclamação** | Apresentar reclamação à ANPD (Brasil) ou autoridade de controlo da UE |

Para exercer qualquer destes direitos, envie um e-mail para **[EMAIL_PRIVACIDADE@DOMINIO]**. Responderemos em até **15 dias úteis** (Brasil/LGPD) ou **30 dias** (UE/GDPR).

## 8. Segurança

Aplicamos medidas técnicas e organizacionais para proteger os seus dados:

- **Encriptação em trânsito:** HTTPS/TLS em todas as comunicações
- **Encriptação em repouso:** Palavras-passe via bcrypt; tokens OAuth encriptados
- **Acesso restrito:** Apenas pessoal autorizado tem acesso aos sistemas
- **Backups:** Backups regulares geridos pelo Supabase
- **Monitorização:** Logs de auditoria para deteção de acessos suspeitos

Em caso de incidente de segurança que afete os seus dados, será notificado em até **72 horas**, conforme exigido por LGPD/GDPR.

## 9. Cookies e Tecnologias Similares

Utilizamos apenas cookies **essenciais** ao funcionamento:

- **Cookies de sessão Streamlit:** Manter o estado da aplicação durante o uso
- **Cookies Supabase Auth:** Manter a sessão de login

**Não utilizamos:** Google Analytics, Facebook Pixel, cookies publicitários, ou rastreamento entre sites.

Consulte a nossa [Política de Cookies](./cookies.md) para mais detalhes.

## 10. Menores de Idade

O Serviço é destinado a maiores de 18 anos. Não recolhemos conscientemente dados de menores. Se identificar que um menor utilizou o Serviço sem autorização, contacte-nos imediatamente.
