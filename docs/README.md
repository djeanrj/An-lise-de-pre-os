# 📄 Documentos Legais — Setup

Esta pasta contém os documentos legais do **Viabilidade de Vendas** prontos para hospedar no GitHub Pages.

## 🚀 Como ativar o GitHub Pages

### Passo 1: Mover esta pasta para o repositório

No teu computador local (ou direto pelo GitHub web):

1. Copia esta pasta `docs_legal/` para o repositório `djeanrj/An-lise-de-pre-os`
2. Renomeia para `docs/` (GitHub Pages usa este nome por padrão)

### Passo 2: Ativar Pages no GitHub

1. Vai a https://github.com/djeanrj/An-lise-de-pre-os/settings/pages
2. Em **Source**, escolhe:
   - Branch: `main`
   - Folder: `/docs`
3. Clica **Save**
4. Aguarda 1-2 minutos para o build

### Passo 3: Confirmar URL

A URL será algo como:
```
https://djeanrj.github.io/An-lise-de-pre-os/
```
